Świat Zwierząt - Blog

Projekt zaliczeniowy 

O projekcie
Portal zawiera informacje o popularnych gatunkach zwierząt, ich cechach, wadze i wzroście, a także sekcję ciekawostek oraz interaktywny slider i filtr kategorii.

Wykorzystane technologie
-HTML5 znaczniki semantyczne, struktura dokumentu
-CSS3 flexbox, CSS Grid, zmienne CSS, media queries, responsywność
-JavaScript interaktywny slider, filtrowanie elementów, menu mobilne, efekt wyłaniania sekcji
